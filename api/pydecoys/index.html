pydecoys

Provides:

  1. A CLI app to easily generate a decoy fasta file from a target fasta file

  2. A comprehensive Python API with IO, Generator and single data functions

  3. Easy implementation of custom decoy strategies

  4. Full integration with Biopython

Note

Some functionalities of PyDecoys require Biopython. Those functionalities are documented as such.

Functions that perform IO operations:

from_fasta(input, strategy, decoy_tag='decoy_', prefix=True)[source]

Apply a decoy generator to entries from a fasta file. Requires Biopython.

Parameters:

  • input (_PathOrIO) – Path or handle to a fasta file.

  • strategy (_Strategy) – Lower case string specifying the decoy strategy to be used, or a strategies.DecoyGenerator function.

  • decoy_tag (str) – An optional tag that is appended to each input’s id. Defaults to ‘decoy_’.

  • prefix (bool) – If True, decoy_tag is prefixed, otherwise it’s suffixed. Defaults to True.

Yields:

SeqRecord – A decoy version of the next SeqRecord in the file.

Return type:

Iterable[SeqRecord]

Notes

This function calls from_SeqRecords() internally, so pydecoys.from_fasta(input, strategy) is equivalent to:

>>> from Bio import SeqIO
>>> targets = SeqIO.parse(input, format='fasta')
>>> decoys = from_SeqRecords(targets, strategy)

This function will automatically pass the sequences as context to an unset strategies.ContextfulGenerator strategy and reset it afterwards.

to_fasta(input, output, strategy, decoy_tag='decoy_', prefix=True, concat=False)[source]

Apply a decoy generator to a set of sequences and write them to a file. Requires Biopython.

Parameters:

  • input (_PathOrIO | Iterable[SeqRecord] | SeqRecord) – A list (or iterator) of SeqRecord objects, a single SeqRecord, or the path or handle to a fasta file.

  • output (_PathOrIO) – Path or handle to a fasta file.

  • strategy (_Strategy) – Lower case string specifying the decoy strategy to be used, or a strategies.DecoyGenerator function.

  • decoy_tag (str) – An optional tag that is appended to each input’s id. Defaults to ‘decoy_’.

  • prefix (bool) – If True, decoy_tag is prefixed, otherwise it’s suffixed. Defaults to True.

  • concat (bool) – If True, output fasta will have both target and decoy entries. All targets will be first, then all decoys. Defaults to False.’

Returns:

The number of entries written (as an integer).

Return type:

int

Notes

While _PathOrIO is defined as str | os.PathLike[str] | typing.TextIO, the runtime isinstance check is done against io.TextIOBase.

This function calls from_SeqRecords() internally, so count = pydecoys.to_fasta(targets, output, strategy) where targets is an Iterable[SeqRecord] is equivalent to:

>>> decoys = from_SeqRecords(targets, strategy)
>>> count = SeqIO.write(decoys, output, format='fasta')

If True, the concat flag will cause all sequences to be loaded into a list prior to decoy generation to avoid parsing sequences twice.

This function will automatically pass the sequences as context to an unset strategies.ContextfulGenerator strategy and reset it afterwards.

from_SeqRecords(sequences, strategy, decoy_tag='decoy_', prefix=True)[source]

Apply a decoy generation strategy to a set of sequences. Requires Biopython.

Parameters:

  • sequences (Iterable[SeqRecord] | SeqRecord) – A list (or iterator) of SeqRecord objects, or a single SeqRecord.

  • strategy (_Strategy) – Lower case string specifying the decoy strategy to be used, or a strategies.DecoyGenerator function.

  • decoy_tag (str) – An optional tag that is appended to each input’s id. Defaults to ‘decoy_’.

  • prefix (bool) – If True, decoy_tag is prefixed, otherwise it’s suffixed. Defaults to True.

Yields:

SeqRecord – A decoy version of the next SeqRecord in sequences.

Return type:

Generator[SeqRecord, None, None]

Examples

>>> from Bio.SeqRecord import SeqRecord
>>> from Bio.Seq import Seq
>>> seqs = [
...     SeqRecord(Seq('DNIDYKAVYR'), 'seq1'),
...     SeqRecord(Seq('QSYMCTVTHP'), 'seq2'),
...     SeqRecord(Seq('CQWSLTEELL'), 'seq3'),
... ]
>>> for decoy in from_SeqRecords(seqs, 'reverse'):
...     print(f'{decoy.id}: {decoy.seq}')
decoy_seq1: RYVAKYDIND
decoy_seq2: PHTVTCMYSQ
decoy_seq3: LLEETLSWQC

The sequence can be a single value:

>>> from types import GeneratorType
>>> seq = SeqRecord(Seq('DNIDYKAVYR'), 'seq1')
>>> decoy = from_SeqRecords(seq, 'reverse')
>>> isinstance(decoy, GeneratorType)  # Still returns a Generator
True

Notes

This function will automatically pass the sequences as context to an unset strategies.ContextfulGenerator strategy and reset it afterwards.

from_tuples(sequences, strategy, decoy_tag='decoy_', prefix=True)[source]

Apply a decoy generation strategy to a set of tuples.

Differently from other functions in this module, from_tuples cannot accept a single tuple. Be sure to always pass an iterable of tuples. If you’d like, you can use tuple_as_decoy() instead.

Parameters:

  • sequences (Iterable[tuple[str, T]]) – A list (or iterator) of tuple objects. The first item should be the seqid, and the second item should be the sequence.

  • strategy (_Strategy) – Lower case string specifying the decoy strategy to be used, or a strategies.DecoyGenerator function.

  • decoy_tag (str) – An optional tag that is appended to each input’s id. Defaults to ‘decoy_’.

  • prefix (bool) – If True, decoy_tag is prefixed, otherwise it’s suffixed. Defaults to True.

Yields:

tuple[str, T] – A decoy version of the next tuple in sequences.

Return type:

Generator[tuple[str, T], None, None]

Examples

>>> seqs = [
...     ('seq1', 'DNIDYKAVYR'),
...     ('seq2', 'QSYMCTVTHP'),
...     ('seq3', 'CQWSLTEELL'),
... ]
>>> for decoy in from_tuples(seqs, 'reverse'):
...     print(f'{decoy[0]}: {decoy[1]}')
decoy_seq1: RYVAKYDIND
decoy_seq2: PHTVTCMYSQ
decoy_seq3: LLEETLSWQC

Type is preserved:

>>> seqs = [
...     ('seq1', Seq('DNIDYKAVYR')),
...     ('seq2', Seq('QSYMCTVTHP')),
...     ('seq3', Seq('CQWSLTEELL')),
... ]

...     print(isinstance(decoy[1], Seq))
True
True

Notes

from_seqs(sequences, strategy)[source]

Apply a decoy generation strategy to a set of sequences.

Parameters:

  • sequences (Iterable | T) – A list (or iterator) of SeqLike objects, or a single SeqLike.

  • strategy (_Strategy) – Lower case string specifying the decoy strategy to be used, or a strategies.DecoyGenerator function.

Yields:

T – A decoy version of the next sequence in sequences.

Return type:

Generator[T, None, None]

Examples

>>> seqs = [
...     'DNIDYKAVYR',
...     'QSYMCTVTHP',
...     'CQWSLTEELL',
... ]
>>> for decoy in from_seqs(seqs, 'reverse'):
...     print(decoy)
RYVAKYDIND
PHTVTCMYSQ
LLEETLSWQC

Type is preserved:

>>> from Bio.Seq import Seq
>>> seqs = [
...     Seq('DNIDYKAVYR'),
...     Seq('QSYMCTVTHP'),
...     Seq('CQWSLTEELL'),
... ]
>>> for decoy in from_seqs(seqs, 'reverse'):
...     print(isinstance(decoy, Seq))
True
True
True

The sequence can be a single value:

>>> from types import GeneratorType
>>> decoy = from_seqs('DNIDYKAVYR', 'reverse')
>>> isinstance(decoy, GeneratorType)  # Still returns a Generator
True

Notes

This function will automatically pass the sequences as context to an unset strategies.ContextfulGenerator strategy and reset it afterwards.

Note

Those functions try to be lazy whenver possible, but since strategies.ContextulGenerator needs prior access to the target database, lazily loading targets isn’t possible with context-dependant strategies. Thus, target sequences are collected into a list beforehand when using a context-dependant strategy.

Since IO functions all use from_SeqRecords() internally, this is also valid for them.

SeqRecord_as_decoy(sequence, strategy, decoy_tag='decoy_', prefix=True)[source]

Get a decoy from a given SeqRecord.

Parameters:

  • sequence (SeqRecord) – A single SeqRecord.

  • strategy (_Strategy) – Lower case string specifying the decoy strategy to be used, or a strategies.DecoyGenerator function.

  • decoy_tag (str) – An optional tag that is appended to each input’s id. Defaults to ‘decoy_’.

  • prefix (bool) – If True, decoy_tag is prefixed, otherwise it’s suffixed. Defaults to True.

Returns:

A decoy version of sequence.

Return type:

SeqRecord

Examples

>>> from Bio.SeqRecord import SeqRecord
>>> from Bio.Seq import Seq
>>> seq = SeqRecord(Seq('DNIDYKAVYR'), 'seq1')
>>> decoy = SeqRecord_as_decoy(seq, 'reverse')
>>> print(f'{decoy.id}: {decoy.seq}')
decoy_seq1: RYVAKYDIND

Notes

This function won’t give context to strategies.ContextfulGerenator objects. You can get an already set strategies.ContextfulGerenator with get_contextualized_strategy().
