Using the PyDecoys API

PyDecoys has a comprehensive API for integration in Python proteomics workflows.

This section provides some basic examples. Refer to the API Reference for more detailed explanations.

Basic funcionality

PyDecoys’ main API contains useful functions that take a set of target proteins and return decoys. Each function uses a different Python type as representation for targets and decoys.

IO functions

To read a target fasta file and get decoys from it, use from_fasta():

>>> from Bio import SeqIO
>>> import pydecoys
>>> decoys = pydecoys.from_fasta('path/to/targets.fasta', strategy='reverse')

You can also use to_fasta() to write a decoy fasta file using a target dataset:

>>> targets = SeqIO.parse('path/to/targets.fasta', format='fasta')]
>>> # It returns the number of entries written
>>> pydecoys.to_fasta(targets, 'path/to/decoys.fasta', strategy='reverse')
125

For convenience, you can directly pass a path or file handle to to_fasta():

>>> pydecoys.to_fasta(
...     'path/to/targets.fasta',
...     'path/to/decoys.fasta',
...     strategy='reverse'
... )
125

You might want to concatenate the targets and decoys files into a single fasta file. For that, simply set the concat parameter to True:

>>> pydecoys.to_fasta(
...     'path/to/targets.fasta',
...     'path/to/concat.fasta',
...     strategy='reverse',
...     # the resulting fasta will contain both targets and decoys
...     concat=True
... )
250

Iterable functions

Sometimes you might want to hold your data a bit longer before saving it to a file. PyDecoys has dedicated functions to read from and get iterable protein sets. For example, to convert a target SeqRecord iterable into a decoy SeqRecord iterable:

1from Bio import SeqIO
2import pydecoys
3
4targets = SeqIO.parse('path/to/targets.fasta', format='fasta')
5decoys = pydecoys.from_SeqRecords(targets, strategy='reverse')

Similar functions are also available for tuple and str objects representing a protein (not requiring Biopython):

 1import pydecoys
 2
 3tuple_targets: list[tuple[str, str]] = [
 4    ('seq1', 'DNIDYKAVYR'),
 5    ('seq2', 'QSYMCTVTHP'),
 6    ('seq3', 'CQWSLTEELL'),
 7]
 8# Decoys are a `Generator` of `tuple`
 9decoys = pydecoys.from_tuples(tuple_targets, strategy='reverse')
10
11str_targets: list[str] = [
12    'DNIDYKAVYR',
13    'QSYMCTVTHP',
14    'CQWSLTEELL',
15]
16# Decoys are a `Generator` of `str`
17decoys = pydecoys.from_seqs(str_targets, strategy='reverse')

Single data functions

PyDecoys also has some functions to convert a single target to a single decoy. As with the previous example, there’s a dedicated function for SeqRecord objects:

1from Bio import SeqIO
2from Bio.SeqRecord import SeqRecord
3
4# `Bio.SeqIO.read` returns only one `SeqRecord`
5target = SeqIO.read('path/to/target.fasta', format='fasta')
6decoy = pydecoys.SeqRecord_as_decoy(target, strategy='reverse')
7assert instance(decoys, SeqRecord)

And two more functions for tuple and str records:

1tuple_target = ('seq1', 'DNIDYKAVYR')
2decoy = pydecoys.tuple_as_decoy(target, strategy='reverse')
3assert instance(decoy, tuple)
4
5str_target = 'DNIDYKAVYR'
6decoy = pydecoys.seq_as_decoy(str_target, strategy='reverse')
7assert instance(decoy, str)

Note

Although the examples above use a str to represent an aminoacid sequence, from_tuples(), from_seqs(), tuple_as_decoy() and seq_as_decoy() can take Seq or MutableSeq objects as aa sequences, and will return the correct type.

Adding new strategies

You can register a new decoy strategy using the register function:

1import pydecoys
2from pydecoys.strategies import SeqLike
3
4
5def custom_decoys[T: SeqLike](sequence: T) -> T:
6    ...
7
8pydecoys.register('custom-decoys', custom_decoys)
9decoys = pydecoys.from_fasta('path/to/targets.fasta', 'custom-decoys')

Custom strategy functions can also be passed directly:

1import pydecoys
2from pydecoys.strategies import SeqLike
3
4
5def custom_decoys[T: SeqLike](sequence: T) -> T:
6    ...
7
8decoys = pydecoys.from_fasta('path/to/targets.fasta', custom_decoys)
